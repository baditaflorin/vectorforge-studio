# VectorForge Studio

Browser-native vector illustration studio with serious Bezier, color, and GPU-accelerated editing.

Live site: https://baditaflorin.github.io/vectorforge-studio/

Repository: https://github.com/baditaflorin/vectorforge-studio

Support development: https://www.paypal.com/paypalme/florinbadita

## Quickstart

```sh
npm install
make install-hooks
make dev
```

## Project mode

VectorForge Studio is a Mode A GitHub Pages application: no runtime backend,
no secrets, and all user documents stay local in the browser.
