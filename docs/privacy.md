# Privacy

VectorForge Studio v1 has no analytics, no runtime backend, and no account
system.

Documents are stored locally in the browser through IndexedDB. SVG import and
export happen in the browser. The app fetches public repository metadata from:

https://api.github.com/repos/baditaflorin/vectorforge-studio

The app links to:

https://github.com/baditaflorin/vectorforge-studio

https://www.paypal.com/paypalme/florinbadita

No PayPal or GitHub authentication data is handled by this app.
